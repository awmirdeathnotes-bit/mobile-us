# Us 📟

A classic-phone style web app for a private group: login, private messaging, Snake, pixel Text art, Faal, Truth or Dare, ringtones, and owner/admin tools.

## Files
- `index.html` — the whole app (single self-contained file)

## Accounts
- Owner username: `owner69` (change the password from **Settings → Change password** after first login)
- Owner can create admins and users; admins can create users.
- The owner can read all chats — members are told this on the login screen.

## Storage
- Inside Claude (published artifact): shared online storage.
- Hosted anywhere else: saves on each device only. Cross-member messaging needs a backend (e.g. Firebase / Supabase) — planned next step for the Telegram mini app.

## Run locally
Open `index.html` in a browser, or serve with any static host (GitHub Pages works).
